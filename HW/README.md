# 多項式求根原理與 NumPy 實作 (Polynomial Roots Finder)

本專案旨在演示如何使用 Python 的 `numpy` 函式庫求解高次多項式的根，並探討係數排列（升冪 vs 降冪）對程式實作的影響，以及背後的數值分析數學原理。

## 1. 數學問題定義

本程式求解的目標多項式 $P(x)$ 為五次方程式：

$$P(x) = 2x^5 + 4x^4 - 2x^3 - 4x^2 - 10x + 10$$

求根的目標是找出所有滿足 $P(x) = 0$ 的 $x$ 值（包含實數根與複數根）。

## 2. 係數表示法 (Coefficient Ordering)

在數學與程式實作之間，**係數的排列順序**是極易混淆的關鍵。本程式展示了兩種觀點的轉換：

### 數學/泰勒級數觀點 (升冪)
一般數學分析或級數展開時，我們常將常數項設為第 0 項：
$$P(x) = \sum_{i=0}^{n} c_i x^i = c_0 + c_1 x + c_2 x^2 + \dots + c_n x^n$$
在此定義下，係數陣列為 **升冪排列**：
* $c_0 = 10$ (常數項)
* $c_5 = 2$ (最高次項)
* **陣列：** `[10, -10, -4, -2, 4, 2]`

### NumPy/Matlab 慣例 (降冪)
`numpy.roots` 函式要求係數必須按照 **降冪排列** (從最高次項到常數項)：
$$P(x) = c_n x^n + c_{n-1} x^{n-1} + \dots + c_1 x + c_0$$
* **陣列：** `[2, 4, -2, -4, -10, 10]`

> **程式技巧**：若原始資料為升冪排列，必須使用 Python 切片語法 `[::-1]` 進行反轉以符合 NumPy 要求。

## 3. 背後的數學演算法：伴隨矩陣 (Companion Matrix)

您可能會好奇，電腦是如何解出這個五次方程式的？

根據 **阿貝爾-魯菲尼定理 (Abel–Ruffini theorem)**，五次及以上的代數方程式沒有一般的代數公式解（即無法像二次方程式那樣套公式）。因此，`numpy.roots` 並非使用公式，而是將求根問題轉換為 **線性代數中的特徵值問題**。

### 演算法步驟：

1.  **正規化**：將多項式除以首項係數 $a_n$ (在此例中為 2)，使其變為首一多項式 (Monic polynomial)：
    $$x^5 + 2x^4 - x^3 - 2x^2 - 5x + 5 = 0$$

2.  **建構伴隨矩陣 $C$**：
    對於多項式 $x^n + a_{n-1}x^{n-1} + \dots + a_0$，其伴隨矩陣是一個 $n \times n$ 的矩陣，結構如下：
    
    $$
    C = \begin{bmatrix}
    0 & 1 & 0 & \dots & 0 \\
    0 & 0 & 1 & \dots & 0 \\
    \vdots & \vdots & \vdots & \ddots & \vdots \\
    0 & 0 & 0 & \dots & 1 \\
    -a_0 & -a_1 & -a_2 & \dots & -a_{n-1}
    \end{bmatrix}
    $$

3.  **求解特徵值**：
    數學上可以證明，伴隨矩陣 $C$ 的 **特徵值 (Eigenvalues)** $\lambda$ 正好就是原多項式 $P(x)$ 的 **根**。
    
    $$\det(C - \lambda I) = (-1)^n P(\lambda) = 0$$

NumPy 內部呼叫的是 LAPACK 函式庫 (如 `geev`) 來計算這個矩陣的特徵值，從而得到多項式的解。

## 4. 程式碼說明

```python
import numpy as np

# P(x) = 2x^5 + 4x^4 - 2x^3 - 4x^2 - 10x + 10

# 1. 使用者定義順序 (升冪：常數項 -> 最高次項)
c_user_order = [10, -10, -4, -2, 4, 2]

# 2. NumPy 要求順序 (降冪：最高次項 -> 常數項)
c_numpy_order = [2, 4, -2, -4, -10, 10]

# --- 求解 ---

# 方法一：直接傳入降冪列表
roots_1 = np.roots(c_numpy_order)

# 方法二：將升冪列表反轉 ([::-1]) 傳入
roots_2 = np.roots(c_user_order[::-1])

# --- 結果 ---
# 兩者結果將完全相同，包含實數根與複數根 (由 j 表示虛部)。
